Verifiable Event Ledger for Multi-Service Microservices: cryptographically verifiable audit log system for distributed
 microservices using blockchain as a trust anchor

Multiple backend services generate events.
Events are stored in MongoDB.
Events are periodically grouped into immutable batches.
Each batch gets a Merkle Root.
That Merkle Root is anchored to a blockchain.
Later, anyone can cryptographically verify that an event has not been altered, deleted, or moved.
